## 实验要点

request / response 内置对象演示（`lab5/demo/`）+ 综合实例·新闻发布系统登录状态（`newsPub/`）：

1. **request 获取表单数据**：`getParameter` / `getParameterValues` 接收 text、password、select、checkbox、radio、textarea 六类控件（requestDemo1_1 → requestDemo1_2）
2. **request 获取请求信息**：`getHeaderNames` / `getHeader` 遍历请求报文头，以及协议、方法、客户端 IP、服务器端口、上下文路径、请求 URI 等（requestDemo2）
3. **response 控制响应**：`setContentType` 改变输出文档格式（文本 / Excel / Word 保存，responseDemo1）；`setHeader("refresh")` 实现 5 秒自动跳转（responseDemo2）
4. **综合实例 · 新闻发布系统登录状态**：在 [上机4](https://102300671.github.io/jsp-base/posts/上机4/) 骨架基础上接入登录/退出：
   - `doLogin.jsp`：request 接收表单 + `session.setAttribute` 保存登录态 + `response.sendRedirect` 重定向
   - `doLogout.jsp`：`session.invalidate()` 销毁会话后重定向回首页
   - `common/top.jsp`：由上机4 的静态初版修改为按 session 显示登录态

> **top.jsp 的两阶段演进**：该文件在上机4 创建（静态"用户登录"链接），本章加入 session 判断，git 历史分两次提交记录（`git log -p jsp-src/src/main/webapp/newsPub/common/top.jsp`）。本章的修改 diff 如下：
